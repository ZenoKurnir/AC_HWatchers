# AC_HWatchers

[English](README.md)

**アイコミ (Aicomi)** のHシーンを、ほかの女の子たちが見に来るBepInEx 6 (IL2CPP) プラグインです。

Hが始まると、同じエリアにいる近くの女の子たちが集まって見学します。シーンが進むと興奮し、オナニーを始めたり、女の子同士で愛し合ったりします。経験のある見学者は3Pや5Pに参加したり、シーン中の女の子と入れ替わったりできます。

## 機能

- **見学者:** 同じ部屋・エリアにいる近くの女の子(特別な住人も含む)が見に来ます。壁やカメラ、シーン中の人を避けて床に立ちます。
- **反応:** 興奮度に合わせて表情や視線が変わります。
- **オナニー:** 興奮した見学者は立ったまま、しゃがんで、または寝転んでオナニーします。
- **女の子同士:** 「女の子好き」同士の見学者が二人とも興奮すると、愛し合ったり(貝合わせ・立位)、片方がもう片方を愛撫したりします。キスが合うように身長を揃えます。
- **3P:** ゲームの3Pボタンで見学者が一人参加します。見学者のメニューから参加する子を選べます。
- **5P(試験的):** 経験のある見学者が3人以上いれば、3Pボタンで5Pを始められます。5Pでも2人・3人用の体位がすべて選べ、参加していない子は見学します。
- **入れ替え:** ソロ・3P・5Pのどれでも、見学者がシーン中の女の子と入れ替われます。体・服・声が引き継がれ、入れ替わった子は見学者になります。
- **疲れた女の子:** 疲れ果てた子はHの終わりまで疲れたままで、見学中は横になります。入れ替わって入った元気な子は、自分のイク回数で元気な状態から始まります。
- **全員に経験値:** Hに参加した女の子全員が、メインの子と同じH経験・部位経験・H回数を得ます。3Pや5Pボタンでシーンが始め直されても、それまでの分は失われません。
- **見学者の移動:** メニューを開いている間、ゲームの移動ツールでシーンの代わりにその子を動かせます。

### ルール

- **処女**は見学のみです(オナニー、女の子同士、参加、入れ替えはしません)。
- 女の子同士で愛し合うのは、二人とも**女の子好き**の特性を持つ場合だけです。
- 3P・5Pへの参加や入れ替えには、**H経験50以上**が必要です(設定で変更可)。

## 必要なもの

- アイコミ (Aicomi)
- [BepInEx 6 (IL2CPP, bleeding edge)](https://builds.bepinex.dev/projects/bepinex_be)(一般的なMODパックに含まれているもの)

## インストール

1. [Releases](../../releases) ページから `AC_HWatchers-v1.0.0.zip` をダウンロードします。
2. ゲームフォルダ(`Aicomi.exe` があるフォルダ)に展開し、`BepInEx/plugins/AC_HWatchers.dll` となるようにします。
3. ゲームを起動します。

## 操作

| キー | 動作 |
| --- | --- |
| F9 | 見学者を一人呼ぶ |
| Shift + F9 | 見学者を全員帰す |
| Ctrl + 見学者を右クリック | その子のメニューを開く |

見学者メニューには経験値と「女の子好き」かどうかが表示されます。メニューでできること:
- 衣装・服の着脱の変更
- オナニーの開始・停止
- 相手とレズ・愛撫の体位の選択
- シーンへの入れ替え
- 3Pボタンで参加する子に指定
- 帰す

経験のある見学者が十分いるときは、ゲームの3Pボタンの横にある **5P** ボタンで3Pを5Pに切り替えられます。

## 設定

`BepInEx/config/AC_HWatchers.cfg` を編集するか、ConfigurationManager(F1)を使ってください。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| Bring Watchers Automatically | On | Hの開始時に見学者が来る |
| Maximum Watchers | 3 | 同時に見学できる人数(1〜8) |
| Reach (m) | 25 | この距離内の女の子だけが来る |
| Distance (m) | 1.8 | カップルからの距離 |
| Excitement Speed | 1 | 興奮する速さ |
| Masturbation | On | 興奮した見学者がオナニーする |
| Girls Make Love | On | 女の子好き同士が愛し合う |
| Watchers Join 3P | On | 3Pボタンで見学者が参加する |
| Swaps | On | 見学者と入れ替えられる |
| Watchers 5P | On | 3Pボタンで5Pを始められる(試験的) |
| All Positions In 5P | On | 5Pで2人・3人用の体位も選べる |
| Experience To Join | 50 | 参加・入れ替えに必要なH経験 |
| Experience For Every Girl | On | 参加した全員がHの結果を得る |
| Watcher Key | F9 | 見学者を呼ぶキー |
| Detailed Log | Off | 不具合報告用にBepInExのログへ詳細を書く |

## 注意

- 入れ替えの後も、ゲームはH自体をシーン開始時の女の子の分として数えます。ほかの子の分は、結果が書き込まれるときにMODが加えます。
- 淫乱度と好感度はゲームの通りです。
- AC_GroupHAnywhere(全マップで3P・5P)、AC_PovX、AC_Subtitlesと一緒に使えます。
- 不具合を報告するときは **Detailed Log** をオンにして再現し、`BepInEx/LogOutput.log` を添付してください。

## ビルド

.NET 6 SDK以上と、BepInExを一度起動したゲームフォルダ(`BepInEx/interop` があるもの)が必要です。

```
cd src
dotnet build -c Release -p:GameDir="C:\path\to\Aicomi\BepInEx"
```

interopが別の場所にある場合は `-p:InteropDir=<フォルダ>` を追加してください。DLLは `src/bin/Release/net6.0/AC_HWatchers.dll` に出力されます。
